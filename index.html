Text-to-SQL analytics agent

Ask a business question in plain English and get the SQL, a table, a chart and a one-line summary. Follow-ups like "now split that by category" work.

  • Safe on a real database: every query is parsed and checked before it runs (read-only, approved tables, row limit), on a read-only connection with a time limit.
  • Metrics such as revenue and on-time delivery are defined once in a semantic layer, so every answer uses the same formula, and joins that would double count are refused.
  • With an OpenAI or Claude key it uses tool calling and fixes its own SQL from database errors.

Enterprise knowledge assistant

An assistant that answers questions about company policies and SOPs with a citation for every sentence, and says "I couldn't find this" instead of guessing.

  • Hybrid search: meaning-based vector search plus keyword search, merged and re-ranked, so exact terms like form numbers aren't lost.
  • Filters by department, document type and date run inside MongoDB Atlas Vector Search.
  • An evaluation suite measures retrieval, accuracy, faithfulness and refusals, and fails the build if quality drops.

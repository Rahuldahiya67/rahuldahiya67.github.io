# rahuldahiya67.github.io

Personal portfolio of Rahul Dahiya, live at https://rahuldahiya67.github.io

A single static page (HTML + CSS, no build step), served by GitHub Pages.

## Updating

- **Lab projects**: finished projects from [data-ai-lab](https://github.com/rahuldahiya67/data-ai-lab) are listed between the `LAB-PROJECTS` markers in `index.html` (one card each) and in `resume/resume.html` (newest three as bullets).
- **Resume**: `assets/Rahul_Dahiya_Resume.pdf` is built from `resume/resume.html`. Edit the HTML, then run `resume/build.sh` (needs headless Chromium and the Carlito font). The script fails if the resume runs past two pages.

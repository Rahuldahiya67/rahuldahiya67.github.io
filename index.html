Carrier Feed Contract Checker

Checks each carrier's shipment status file against a written YAML data contract before it is loaded. Clean rows go through, bad rows are quarantined with the rule they broke, and the whole file is rejected if too much of it is bad.

Caught all 428 injected defects in a 5,000-row test feed with no false rejects. 68 tests.

Forecasting

Intermittent Demand Forecaster

Forecasts weekly demand for spare parts that sell only some weeks. It classifies each SKU, backtests Croston, SBA and TSB against standard methods, picks a method per SKU and sets reorder points at a target service level.

On intermittent SKUs, error fell from 0.80 (naive) to 0.63 RMSSE with TSB and SBA. 69 tests.

SOP Retrieval Benchmark

Tests whether search over warehouse SOPs that differ by site brings back the right rule for the right site. It scores BM25 search, query expansion with a synonym glossary, a site filter and title headers on 315 labelled questions, including held-out wording.

Expansion raised paraphrase recall@5 from 0.48 to 0.91 but lowered it on held-out wording (0.70 to 0.60). 91 tests.

Data engineering

Rate Card History Loader

Keeps a full history of carrier rate changes so any invoice can be checked against the rate valid on its ship date. It loads an at-least-once change data capture (CDC) stream into an SCD Type 2 table in DuckDB, skips duplicates and replays, quarantines bad or late events, then re-rates invoices.

A replayed batch changed nothing; re-rating 400 invoices found all 21 planted billing errors with no false flags. 88 tests.
